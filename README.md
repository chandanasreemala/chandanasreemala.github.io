# Chandana Sree Mala — GitHub Pages Portfolio

This is a minimalist academic portfolio website designed for GitHub Pages.

## Files

Upload the contents of this folder directly to the root of your GitHub repository:

- `index.html`
- `style.css`
- `script.js`
- `.nojekyll`
- `assets/Chandana_Sree_Mala_CV.pdf`

## Important

For a personal GitHub Pages site, the repository name should be:

```text
yourusername.github.io
```

Then publish from:

```text
Settings → Pages → Deploy from branch → main → /root
```
